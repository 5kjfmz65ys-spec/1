# ردّاد AI

منصة عربية عملية لإدارة خدمة العملاء على واتساب، مع دعم:

- ربط رسمي عبر WhatsApp Business Platform Cloud API.
- ربط تجريبي اختياري عبر WhatsApp Web وBaileys مع تحذير إلزامي.
- صندوق محادثات للموظفين.
- مساعد ذكي مقيد بمعلومات المتجر.
- قاعدة معرفة محلية.
- مزودو AI بمفاتيح العميل: Ollama، OpenAI-compatible، Anthropic، Gemini.
- منتجات وطلبات وتقارير وفريق عمل.
- تعدد منشآت وعزل بيانات وصلاحيات.
- تشفير بيانات الاعتماد بواسطة AES-256-GCM.

## حالة النسخة

هذه **نسخة MVP قابلة للتشغيل** ومبنية على Node.js 22 ومكتبة SQLite المدمجة في Node، لذلك لا تحتاج `npm install` لتشغيل التطبيق الأساسي. الربط التجريبي الحي يحتاج تثبيت Baileys وتشغيل خدمة Gateway منفصلة. التكاملات الخارجية تحتاج حسابات ومفاتيح تخص صاحب المتجر.

## تشغيل سريع

المتطلبات: Node.js 22.5 أو أحدث.

```bash
cp .env.example .env
npm run seed
npm start
```

افتح:

```text
http://localhost:3080
```

حساب التجربة بعد `npm run seed`:

```text
البريد: demo@reddad.local
كلمة المرور: Demo12345!
```

## الأوامر

```bash
npm start       # تشغيل التطبيق
npm run dev     # تشغيل مع إعادة تحميل عند تعديل الخادم
npm run seed    # بيانات تجريبية
npm test        # اختبارات Node المدمجة
npm run verify  # فحص الملفات والهيكل
npm run gateway # بوابة Baileys الاختيارية
```

## إعداد البيئة

انسخ `.env.example` إلى `.env`. في التطوير، إذا تركت `ENCRYPTION_KEY` فارغًا فسينشئ التطبيق مفتاحًا محليًا داخل `data/.dev-encryption-key`. في الإنتاج يجب تعيين مفتاح ثابت من 32 بايت، وإلا سيتوقف التطبيق.

مثال توليد مفتاح:

```bash
openssl rand -hex 32
```

المتغيرات المهمة:

- `PORT`: منفذ التطبيق، الافتراضي 3080.
- `APP_URL`: رابط التطبيق الكامل.
- `DATA_DIR`: مجلد SQLite والملفات المحلية.
- `ENCRYPTION_KEY`: مفتاح تشفير بيانات الاعتماد.
- `WA_GATEWAY_URL`: عنوان بوابة Baileys.
- `WA_GATEWAY_TOKEN`: رمز حماية الاتصال بالبوابة.
- `INTERNAL_WEBHOOK_TOKEN`: حماية أحداث البوابة إلى التطبيق.

## الربط الرسمي

من لوحة التحكم افتح «ربط واتساب» ثم أدخل:

- Phone Number ID.
- WABA ID.
- Access Token.
- App Secret.
- Verify Token.
- إصدار Graph API الحالي كما يظهر في وثائق Meta.

بعد الحفظ يكون Webhook بالشكل:

```text
https://YOUR-DOMAIN/webhooks/meta/CONNECTION_ID
```

يتم التحقق من `X-Hub-Signature-256` قبل معالجة أي حدث. لا تُخزن المفاتيح كنص صريح ولا تعاد للواجهة بعد الحفظ.

## الربط التجريبي

الربط التجريبي غير رسمي وغير معتمد من Meta. قد يتوقف أو يحتاج إلى إعادة ربط أو يتعرض الرقم للتقييد. لا يوجد في المشروع إرسال جماعي أو استيراد قوائم أرقام.

لتشغيله في بيئة فيها شبكة:

```bash
npm install
WA_GATEWAY_TOKEN='ضع-رمزًا-طويلًا' \
INTERNAL_WEBHOOK_TOKEN='ضع-رمزًا-طويلًا-آخر' \
npm run gateway
```

ثم ضع القيم نفسها في `.env` للتطبيق الأساسي. عند إنشاء اتصال تجريبي، يجب الموافقة على التحذيرين قبل السماح ببدء الجلسة. تظهر للمستخدم طريقة الاقتران برقم الهاتف عند دعمها.

> تخزين Baileys في نسخة MVP يعتمد على مجلد محلي بصلاحيات مقيدة. للإنتاج استخدم قرصًا مشفرًا أو Auth Store مشفرًا مخصصًا.

## الذكاء الاصطناعي

كل منشأة تضيف مفتاحها الخاص. لا يوجد مفتاح مركزي تابع للمنصة.

### Ollama

شغّل Ollama محليًا، نزّل نموذجًا مناسبًا للعربية، ثم أدخل Base URL مثل `http://localhost:11434` واسم النموذج من لوحة المساعد.

### OpenAI-compatible

أدخل Base URL الذي ينتهي عادة بمسار API، والمفتاح واسم النموذج. التطبيق يستخدم Chat Completions المتوافقة ويطلب مخرجات JSON.

### Anthropic وGemini

التطبيق يستخدم واجهات HTTP المباشرة، لكن أسماء النماذج لا تُثبت داخل الكود. أدخل النموذج المتاح في حسابك وراجع وثائق المزود الحالية قبل الإنتاج.

## الأمان

- كلمات المرور مشفرة باستخدام scrypt.
- جلسات HttpOnly وSameSite=Lax.
- AES-256-GCM لرموز Meta ومفاتيح AI.
- توقيع Webhook رسمي.
- عزل جميع الاستعلامات حسب `organization_id`.
- Rate limiting أساسي لمحاولات التسجيل والدخول.
- CSP وSecurity Headers.
- تنقية Logs من الحقول الحساسة.
- منع ظهور QR قبل تسجيل الموافقة على التحذير التجريبي.

راجع `docs/SECURITY.md` قبل النشر العام.

## القيود الحالية

- SQLite مناسب للـMVP والتجربة. للشركات متعددة الخوادم انقل طبقة البيانات إلى PostgreSQL.
- لا يوجد رفع ملفات PDF/DOCX في هذه النسخة؛ قاعدة المعرفة تدعم الإدخال النصي والأسئلة والأجوبة.
- تكامل سلة موثق كمرحلة تالية ولم يُفعّل بدون بيانات تطبيق Salla.
- إرسال الوسائط التجريبي يحتاج إضافة تنزيل وفحص وسائط آمن قبل تفعيله.
- لا يمكن اختبار Meta أو مزودي AI دون مفاتيح حقيقية تخص المستخدم.
