# ردّاد AI

نسخة MVP لمنصة عربية لإدارة خدمة العملاء وربط واتساب بالذكاء الاصطناعي.

## ملف المشروع

المشروع الكامل موجود داخل:

`reddad-ai-mvp.zip`

بعد تنزيله وفك الضغط:

```bash
cd reddad-ai
cp .env.example .env
npm run seed
npm start
```

ثم افتح:

`http://localhost:3080`

## حساب التجربة

- البريد: `demo@reddad.local`
- كلمة المرور: `Demo12345!`

## تنبيهات

- لا يحتوي المستودع على ملفات `.env` حقيقية أو مفاتيح سرية.
- الربط الرسمي يحتاج بيانات WhatsApp Cloud API الخاصة بصاحب المتجر.
- الربط التجريبي عبر Baileys غير رسمي وقد يتوقف أو يتعرض الرقم للتقييد.
- لم يتم اختبار اتصال Meta أو رقم واتساب حقيقي داخل نسخة التسليم.
