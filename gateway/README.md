# بوابة الربط التجريبي

هذه الخدمة اختيارية وتستخدم Baileys، وهو ربط غير رسمي وغير معتمد من Meta. التطبيق الأساسي يعمل دونها.

> تنبيه أمني: نسخة MVP تستخدم `useMultiFileAuthState` داخل مجلد محلي بصلاحيات مقيدة. للإنتاج استخدم قرصًا مشفرًا أو استبدلها بمخزن اعتماد مشفر على مستوى الحقول. لا تنسخ مجلد الجلسات ولا ترفعه إلى Git.

التشغيل بعد توفر الشبكة:

```bash
npm install
WA_GATEWAY_TOKEN='...' INTERNAL_WEBHOOK_TOKEN='...' npm run gateway
```
