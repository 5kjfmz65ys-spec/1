# المعمارية

## التطبيق الأساسي

`server.mjs` خادم HTTP بدون تبعيات خارجية، يقدم الواجهة وواجهات API وMeta Webhook. التخزين عبر `node:sqlite`، والجلسات في قاعدة البيانات.

## الطبقات

- `src/auth.mjs`: التسجيل، الدخول، الجلسات والعضويات.
- `src/db.mjs`: المخطط وعمليات SQLite.
- `src/services.mjs`: منطق المنشأة والاتصالات والمحادثات والمعرفة.
- `src/inbound.mjs`: استقبال الرسائل وتحديث المحادثات والرد التلقائي.
- `src/agent.mjs`: البحث في المعرفة وحواجز النطاق وتوليد الرد.
- `src/providers`: موصلات WhatsApp وAI.
- `gateway/server.mjs`: عملية مستقلة للربط التجريبي.

## تعدد المنشآت

كل جدول تشغيلي يحتوي `organization_id`. لا يقبل الخادم هذا المعرف كقيمة موثوقة من النموذج؛ يحصل عليه من الجلسة والعضوية.

## مسار الرسالة الرسمية

1. Meta ترسل Webhook إلى مسار الاتصال.
2. الخادم يتحقق من التوقيع.
3. يمنع تكرار الحدث والرسالة.
4. ينشئ جهة الاتصال والمحادثة.
5. يحفظ الرسالة.
6. إذا كان وضع المحادثة `ai_active` يشغل المساعد.
7. الرد يُرسل عبر Cloud API ويُحفظ.
