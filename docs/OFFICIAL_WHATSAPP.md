# إعداد WhatsApp Cloud API الرسمي

1. أنشئ تطبيق أعمال في Meta وأضف منتج WhatsApp.
2. جهز رقم WhatsApp Business وPhone Number ID وWABA ID.
3. أنشئ Access Token مناسبًا للإنتاج.
4. اختر App Secret وVerify Token خاصًا بك.
5. أضف الاتصال من لوحة ردّاد.
6. انسخ مسار Webhook الظاهر من معرّف الاتصال.
7. اشترك في أحداث الرسائل وحالات التسليم المطلوبة.
8. اختبر الاتصال من اللوحة.

إصدار Graph API لا يكتب ثابتًا في المشروع؛ أدخله حسب الإصدار الحالي الذي تستخدمه في حساب Meta.
