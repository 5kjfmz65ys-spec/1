# الربط التجريبي غير الرسمي

Baileys يتصل بواجهة WhatsApp Web كجهاز مرتبط. هذا الربط غير معتمد من Meta وقد يتأثر بتغييرات WhatsApp أو Baileys.

## الضوابط

- لا إرسال جماعي.
- لا رسائل باردة.
- لا استيراد قوائم أرقام.
- لا أدوات للتحايل على الحظر.
- الموافقة على التحذير إلزامية قبل الجلسة.
- استخدام رقم اختبار أولًا.

## التشغيل

ثبّت الحزمة الاختيارية ثم شغّل `npm run gateway`. يجب تطابق رموز `WA_GATEWAY_TOKEN` و`INTERNAL_WEBHOOK_TOKEN` بين الخدمتين.
